Pengaturan Autorun Startup Windows

Sistem Bel Otomatis SMKN 1 Moilong langsung aktif setiap kali PC/Laptop dinyalakan

⚙️ Parameter Peluncuran Otomatis (Auto-Config):
🏆 Metode Tercepat & Paling Praktis (Cukup 1-Klik)

Script batch Windows ini secara cerdas mendeteksi Google Chrome atau Microsoft Edge di komputer sekolah, membuat shortcut di folder Startup Windows Anda, dan mengonfigurasi izin audio bel tanpa perlu interaksi manual.

📝 Langkah Pemakaian di Windows:
  1. Klik tombol "Unduh Pasang-Autorun-Bel-Moilong.bat" di atas.
  2. Buka folder Downloads di laptop/PC Windows Anda.
  3. Klik dua kali (double-click) pada file Pasang-Autorun-Bel-Moilong.bat. (Jika muncul Windows SmartScreen, klik "More info" / "Info selengkapnya", lalu pilih "Run anyway" / "Tetap jalankan").
  4. Jendela otomatis membuat shortcut dan menampilkan notifikasi [SUKSES].
  5. Selesai! Saat komputer dinyalakan, Bel Otomatis SMKN 1 Moilong akan langsung terbuka otomatis.
🤫 Peluncur Senyap (Tanpa Jendela Hitam Command Prompt)

File VBScript ringan (Visual Basic Script) yang langsung meluncurkan browser secara hening di latar belakang saat pengguna login ke Windows.

📝 Cara Memasang File .vbs:
  1. Unduh file Bel-Sekolah-Startup.vbs di atas.
  2. Tekan tombol Win + R di keyboard.
  3. Ketik shell:startup lalu tekan Enter. Folder Startup Windows akan terbuka.
  4. Pindahkan (Cut/Paste) file Bel-Sekolah-Startup.vbs ke dalam folder tersebut.
📱 PWA Native OS Integration (Chrome 91+ & Edge)

Aplikasi telah dilengkapi Web App Manifest resmi dengan kapabilitas run_on_os_login sehingga browser Chrome dan Edge dapat mengelolanya langsung di pengaturan startup Windows.

Status Run On OS Login (Browser API): Memeriksa kapabilitas browser...
📝 Cara Pasang via Chrome / Edge:
  1. Di Google Chrome atau Microsoft Edge, klik ikon Install / Pasang Aplikasi di ujung kanan address bar (sebelah kanan bintang bookmark).
  2. Atau klik menu titik tiga ⋮ → Simpan dan Bagikan → Pasang Bel Otomatis SMKN 1 Moilong.
  3. Setelah terpasang, jendela konfirmasi akan menanyakan: centang kotak "Mulai otomatis saat Anda masuk ke komputer" (*Start app when you sign in*).
  4. Aplikasi akan langsung muncul di daftar Startup Task Manager Windows.
📝 Langkah Membuka Folder Startup Windows:

Folder Startup Windows terletak di path:
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup

Segala file shortcut (.lnk), script (.bat / .vbs), atau tautan (.url) yang diletakkan di dalam folder tersebut akan dijalankan secara otomatis oleh sistem operasi Windows setiap kali pengguna melakukan login atau menyalakan PC.

Tips: Gunakan mode App Windowed untuk tampilan layar bersih tanpa address bar.
